## Overview

**Phils** is an editorial discovery platform designed to cultivate thoughtful engagement with philosophical schools of thought, classical paradoxes, and cognitive frameworks. 

### Design Persona: The Contemplative Library
The user interface avoids algorithmic sensory overload, hyper-saturated notification badges, and disposable micro-interactions. Instead, Phils draws inspiration from fine bookbinding, tactile library index cards, warm archival papercraft, and traditional print typesetting.

### Operating Modes
- **Experience (The Discovery Deck)**: A tactile 3D physical card stack that invites deliberate horizontal swipe discovery. Each card behaves like a thick archival stock folio with realistic physical inertia, progressive scale interpolation, and a subtle corner dog-ear fold.
- **Read (The Long-Form Reader)**: A progressive reading environment offering dual depth levels:
  1. **Quick Overview (~2 min read)**: Synthesizes core claims, origin, and key thinkers into an accessible briefing.
  2. **Deep Dive (~6 min read)**: An expansive, six-section dialectic breakdown covering theoretical foundations, counter-arguments, thinker biographies, and step-by-step practical decision scenarios.

## Typography

Phils employs an **Editorial Typographic Trinity** across the experience:

1. **Editorial Serif (`FontFamily.Serif`)**:
   - Used for primary conceptual hooks, hero questions, philosophical quotes, section headers, and big idea titles.
   - Conveys intellectual weight, antiquity, and dignity.
2. **App Sans (`FontFamily.SansSerif`)**:
   - Used for sustained body copy, multi-line explanations, historical context, scenario steps, and general UI labels.
   - Tuned for effortless optical reading with generous line heights (`lineHeight = 23.sp` on `15.sp` body).
3. **Catalog Monospace (`FontFamily.Monospace`)**:
   - Used for structural classification: category eyebrows (`PHILOSOPHY`, `PARADOX`), numerical step indicators (`01`, `02`), dates/eras (`1908–1986`), and reading duration hints (`~6 MIN READ`).
   - Conveys archival precision, reminiscent of a curated index ledger.

## Layout

### 1. Spatial Rhythm Scale
All layouts adhere to an 8-point base spatial system:
- `4dp`: Micro spacer (icon-to-text gap, badge internal padding).
- `8dp`: Compact gap (title to description, list item margin).
- `12dp`: Standard component separation (chips spacing, mini card margin).
- `16dp`: Standard container padding (inner card padding on mobile, row gaps).
- `20dp`: Viewport horizontal padding for the swipe deck.
- `24dp`: Viewport edge padding for editorial detail reading and dialog sheets.
- `28dp`: Group separation (between major sections in Quick Overview).
- `36dp`: Major chapter separation in Deep Dive reading view.

### 2. Viewport & Window Inset Architecture
- **Edge-to-Edge**: Android `enableEdgeToEdge()` is activated at the Activity level.
- **Top Insets**: System status bar is handled via `Modifier.statusBarsPadding()`.
- **Bottom Insets**: System navigation bar is handled via `Modifier.navigationBarsPadding()`.
- **Deck Offset**: The card deck rests with a bottom margin of `86dp`, perfectly clearing the floating bottom navigation dock without clipping content.

## Elevation & Depth

Phils replaces heavy, high-blur dropshadows with **tactile physical layering and tonal stacking**.

### 1. The 3D Card Stack Physical Model
The home deck (`DiscoverScreen`) layers three physical cards simultaneously in the viewport to generate authentic tangible depth:

```
[ Slot 2: Third Card ]   <- Scale: 0.88, Rotation: -5.5°, Translation: X: -30dp, Y: 48dp, Alpha: 0.85
     [ Slot 1: Second Card ] <- Scale: 0.94, Rotation: +4.5°, Translation: X: +34dp, Y: 24dp, Alpha: 0.95
          [ Slot 0: Front Card ]  <- Scale: 1.00, Rotation: -2.5° + drag, Translation: dragX, Alpha: 1.00
```

### Motion & Drag Physics
- **Drag Tracking**: Primitive float offsets tracked via `graphicsLayer { ... }` lambdas, guaranteeing zero recomposition overhead during gesture updates.
- **Dismissal Threshold**: `95dp`. Crossing this distance triggers a smooth throw exit animation to `460dp`.
- **Spring Physics**:
  - Dismiss throw: `dampingRatio = 0.82f`, `stiffness = Spring.StiffnessMedium` (snappy, physical flick).
  - Snapback return: `dampingRatio = 0.72f`, `stiffness = Spring.StiffnessLow` (gentle, organic settling).
- **Sub-Layer Interpolation**: As the front card is dragged, the second card simultaneously interpolates its scale from `0.94 -> 1.0`, its angle from `+4.5° -> -2.5°`, and its offset from `34dp -> 0dp`, creating an illusion of physical card ascension.

### 2. Floating Navigation Bar Elevation
- `elevation = 16dp` with custom dual-color shadow:
  - `ambientColor`: `theme.shadowSoft` (diffuse floor shadow).
  - `spotColor`: `theme.shadow` (directional drop occlusion).

- Located immediately below the hero card on the detail screen.
- Segmented pill container (`16dp` radius, `theme.surface` background, `theme.line` border).
- Two interactive tabs with clear reading commitment indicators:
  - `Quick Overview` (`~2 min read`) with lightbulb icon.
  - `Deep Dive` (`~6 min read`) with open book icon.

- Rendered using `@OptIn(ExperimentalLayoutApi::class) FlowRow` with `Arrangement.spacedBy(10.dp)`.

### 4. Practical Scenario Card
- Multi-step real-world application container (`16dp` radius, `theme.surface`).
- Displays situational context, numbered step circle badges (`1`, `2`, `3`), actionable guidance, and an italicized reflection summary.

### 5. Floating Pill Bottom Navigation Bar
- Dimensions: `height = 64dp`, pill radius `999dp`, horizontal margin `24dp`.
- Floating dock suspended above screen content with blur-tinted `theme.navBg`.
- Four navigation destinations: `Discover`, `Search`, `Saved`, and `You`.
- Automatically hides with a slide-down animation when viewing long-form article details.

## Do's and Don'ts

### Typography
- **DO** use `FontFamily.Serif` for philosophical questions, titles, and inspirational quotes.
- **DO** use `FontFamily.SansSerif` with generous line-heights (`22sp–24sp`) for multi-sentence reading blocks.
- **DO** use `FontFamily.Monospace` for timestamps, metadata, reading times, and category tags.
- **DON'T** use Serif for long body paragraphs (causes visual vibration and optical fatigue on mobile screens).
- **DON'T** allow thinker chips or badges to wrap text into vertical character stacks (always enforce `maxLines = 1, softWrap = false`).

### Colors & Theming
- **DO** retrieve chromatic tones through `getMoodTone(discovery.mood, theme.isDark)` to preserve theme compatibility.
- **DO** use `moodTone.accent` for emphasis elements (eyebrows, thinker links, quotes).
- **DON'T** hardcode raw Hex colors inside UI composables.
- **DON'T** use high-saturation neon primaries; Phils colors are inspired by natural minerals, parchment, and aged pigments.

### Layout & Gestures
- **DO** perform drag gesture transformations inside `Modifier.graphicsLayer { ... }` to avoid recomposition frames.
- **DO** maintain bottom padding (`86dp`) on scrollable list views to avoid clipping behind the floating dock.
- **DON'T** shuffle or re-order deck collections inside `@Composable` functions on recomposition (always perform shuffles in repositories or ViewModels on startup).
- **DON'T** conditionally hide the reading depth selector; synthesize fallback sections for all cards so users can explore both Quick Overview and Deep Dive universally.
